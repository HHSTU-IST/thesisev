# 基于边缘计算的目标检测系统设计与实现

## 摘要

本文研究基于边缘计算的目标检测系统设计与实现。首先分析边缘计算场景下的目标检测需求，随后完成系统总体设计、关键算法选型与数据采集方案。实验结果表明，所提方案在检测精度与实时性之间取得了较好平衡，验证了边缘计算应用于目标检测的技术可行性，具有较好的工程应用价值。

关键词：边缘计算；目标检测；深度学习；嵌入式系统

## Abstract

This paper studies the design and implementation of an edge computing based object detection system. The requirements of object detection in edge scenarios are analyzed, and the overall system architecture together with the key algorithm selection is presented. Experimental results show that the proposed scheme achieves a good balance between detection accuracy and real-time performance.

Keywords: edge computing; object detection; deep learning; embedded system

# 1 绪论

## 1.1 研究背景与意义

随着物联网设备的快速增长，海量视频数据需要在网络边缘完成实时处理。传统云计算架构存在带宽占用高、响应延迟大等问题，因此边缘计算成为目标检测任务的重要部署形态。本文围绕边缘场景下的目标检测系统展开研究，具有明确的工程应用价值。

## 1.2 国内外研究现状

国内外学者对目标检测算法开展了大量研究。基于深度学习的检测方法在精度上显著优于传统方法，但模型计算量较大，难以直接部署在资源受限的边缘设备上。因此，模型轻量化与硬件加速成为当前研究热点。

# 2 需求分析与总体设计

## 2.1 系统需求分析

本文设计的系统需要满足实时性、准确性与可部署性三方面需求。实时性要求单帧处理延迟满足边缘节点约束；准确性要求对常见目标保持较高检出率；可部署性要求系统能够运行在嵌入式平台之上。

## 2.2 系统总体架构

系统总体架构分为感知层、边缘计算层与应用层。感知层负责图像采集，边缘计算层完成目标检测推理，应用层提供结果展示与业务接口。本文重点实现边缘计算层中的检测算法与推理优化。

## 2.3 关键技术选型

经过对比分析，本文选择轻量化卷积神经网络作为基础检测模型，并采用模型剪枝与量化技术降低计算开销。软件层面使用嵌入式推理框架完成模型部署，硬件层面选用低功耗边缘计算开发板进行验证。

# 3 系统详细设计与实现

## 3.1 数据采集与预处理

数据采集阶段构建了包含多类目标的标注数据集。预处理环节完成图像缩放、归一化与数据增强，以提升模型对不同场景的适应能力。实验数据按比例划分为训练集、验证集与测试集。

## 3.2 检测模型设计

模型设计阶段采用主干网络加检测头的结构。主干网络负责特征提取，检测头输出目标类别与位置。本文对网络结构进行了针对性改进，在保持精度的前提下减少参数量与计算量。

## 3.3 系统实现

系统实现基于嵌入式推理框架完成。推理模块负责加载模型并执行前向计算，通信模块负责与感知层和应用层交互。针对资源受限环境，实现了模型量化与内存复用等优化策略。

# 4 实验与结果分析

## 4.1 实验环境与评价指标

实验平台包括边缘计算开发板与服务器。评价指标采用平均精度均值与单帧处理时间。实验对比了不同模型在边缘设备上的精度与速度表现。

## 4.2 实验结果分析

实验结果表明，本文提出的改进模型在精度上接近未压缩模型，同时推理速度显著提升。通过消融实验验证了各优化模块的有效性，分析结果与设计预期一致。综上，本文方案满足边缘场景目标检测的实时性与准确性要求。
